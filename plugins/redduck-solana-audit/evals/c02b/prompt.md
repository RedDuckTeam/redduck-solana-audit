Audit the Solana program in ./program for security issues.

Write your findings to solana-audit-report.md in the current directory. For every finding, write a block with these three lines:

Severity: <Critical|High|Medium|Low|Info>
Location: <path>:<line>
Mechanism: <what is wrong and how it can be abused, in one or two sentences>

Architecture problems count as findings too (for example liveness, centralization or scalability problems), not only bugs in a single line. If you find no issues, write "No findings." in the report.

When you are done, repeat the list of findings in your final message.
